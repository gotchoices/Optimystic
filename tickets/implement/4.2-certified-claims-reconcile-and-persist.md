New cases (new inner `describe`):
1. **Single certified holder heals where corroboration declines**: one peer, valid proof with
   matching digest, `repairCorroborationClusterSize: 10`. Expect: saved once, payload right,
   `saved[0].proof === proof`, no penalties.
2. **Digest-contradicting content rejected, server penalized, repair continues**: two peers,
   SAME valid proof (digest = honest bytes); `evil` serves tampered bytes, `honest` matching;
   `repairCorroborationClusterSize: 10`. Expect: heal lands honest payload, penalties
   `[{ evil, InvalidRestoration }]`, `saved[0].proof === proof`.
3. **Unparseable proof → ordinary uncertified corroborator, no penalty**: two peers serving the

   by plain corroboration, penalties empty, `saved[0].proof === undefined`.
4. **Certified rev equivocation declines + distinct log**: two peers, valid proofs for the same
   rev under DIFFERENT actionIds (two `makeSignedProof` calls, different cohorts fine; simplest:
   both serve the SAME block bytes and each commit declares that digest, so no digest penalties).

5. **Certified content equivocation declines + distinct log**: two proofs for the SAME

   `reconcile:certified-content-equivocation` with both hashes.
6. **Corroboration-only heal persists no proof**: two proof-less peers agreeing,
