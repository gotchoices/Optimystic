# Complete: lock the namespace tree shut, and finish the reference table

## What shipped

**Lint rule (`eslint.config.js`).** Two `no-restricted-syntax` selectors over
`packages/*/src/**/*.ts` — all packages, so a future package that embeds libp2p inherits the
guard:

| Selector | Why |
|---|---|
| `CallExpression[callee.property.name='forComponent']` | libp2p's `components.logger.forComponent('x')` yields the bare namespace `x`, which `DEBUG=optimystic:db-p2p:*` never matches |
| `ImportDeclaration[source.value='debug']` | bypasses the package's `src/logger.ts`, the only thing that prepends `optimystic:<package>:` |

The exemption block for `packages/*/src/logger.ts` and `packages/reference-peer/src/cli.ts`
re-declares the rule with **only** the `forComponent` selector rather than switching it `'off'`,
because flat config replaces a rule's whole config: those files may import `debug`, but still may
not reach for libp2p's component logger.

**Structural guard tests (`packages/db-p2p/test/logger.spec.ts`).** Five specs under
`describe('db-p2p log-namespace guards')`, scanning `src/` resolved from the spec file (never
`process.cwd()`, never a walk that could reach `dist/`), with comments blanked first so a prose
mention of a banned construct is not a violation:

- finds source files to scan at all (guards the guards — currently 142 files)
- never calls `.forComponent(`
- imports `debug` only in `src/logger.ts`
- documents every emitted sub-namespace in `docs/debugging.md`
- **emits every sub-namespace the table documents** *(added during review — see below)*

**`docs/debugging.md`.** The db-p2p table went from 10 rows to 45, split into seven `####`
sub-tables by subsystem, with each description written from the actual `log(...)` format strings in
the file that builds the logger. The "Adding new loggers" section now opens with the rule the lint
rule enforces. Two `DEBUG` recipes were annotated (`cluster` is an exact match, not a prefix) and
the transaction-lifecycle recipe widened to `cluster*` + `coordinator-repo*`.
